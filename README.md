# 图绘工作台 · Figure Studio

把原始数据快速变成可自由编辑的论文配图。粘贴表格、生成图表，然后在画布上像设计工具一样调整每一个元素。

> 当前为预发布构建。发布到 GitHub 前请先阅读 [RELEASING.md](RELEASING.md)。

## 功能

- **可编辑数据表**：像 Excel 一样增删行列、改列名、粘贴区域、编辑单元格；图表自动跟随数据重建。
- **科研图表**：分组柱状图、堆叠柱状图、折线图、面积图、散点图、饼图；误差线、图例、网格、数值标签。
- **论文配色**：Nature、Cell、Science、Lancet、NEJM、Okabe–Ito、单色。
- **全元素编辑**：坐标轴、刻度、图例、每根柱子、每个散点、每段文字都是独立对象，可拖动、缩放、改色、改字体、调图层。
- **画布工具**：框选、多选、吸附、对齐分布、撤销重做、自动保存。
- **科研素材**：17 个矢量图标（细胞、DNA、蛋白、抗体、病毒、细菌、培养皿等）、分图字母、图注、显著性括号、常用符号。
- **导出**：免费版 PNG 带水印；专业版无水印 PNG 300 dpi、SVG 矢量图；工程 JSON 随时导入导出。

## 安装

### 从插件市场安装

在 DSH 中打开 **Plugins → Discover → Add index source**，添加：

```
https://raw.githubusercontent.com/xiaoqiqizi0309/-/main/market/index.json
```

然后搜索 **图绘工作台 / Figure Studio** 并安装。

> 通过 GitHub 源安装时，DSH 使用 pnpm 拉取 Git 仓库，用户本机需要已安装 Git。

### 本地开发安装

```powershell
# 在 dsh-figstudio 目录
node scripts\build.mjs
```

然后用 `plugin_manager` 的 `install_bundle` 安装本目录，或按 DSH 插件开发文档操作。
